# labels/ — KSD 新模型标注

二重影 KSD 脚本的**结构化标注**，由逆向分析得出。

## 格式

```
# 场景 005  新模型标注
# 头部 10 字节，正文 20132 字节
# 命令 = 明文 16 位小端字 1..68；文本 = XOR-0xFF
# 格式:  <正文偏移>  [命令字] 名称  | 文本

        0  Se\017.wav
       10  [字 53] 对象表
       72  「・・・」
      156  [字  6] 选项/参数4
      158  <数据>  1196   ← 跳转目标
      164  ◆起床
```

## 关键结论

- **命令** = 明文 16 位小端字，取值 `1..68`
- 分派表在 exe 的 `0x414364`，68 项，索引 = 命令字 − 1
- **文本** = 原字节 `XOR 0xFF`
- **选项定义** = `◆选项文本` + `[字6 或 63]` + `<16位正文偏移>` + `[字0]`
  - 该偏移即**分支跳转目标**，指向正文字节坐标
  - 注意：偏移常落在文本段内部，不是元素边界

## 场景

- 主线 `001~046` 单链
- 插入支线 `101~118`
