## 已知问题

### 0. 字符替换表

汉化版 KSD 里的中文是用**日文字形**拼的（凜→你、説→说、這→这…）。
`uif_config.json` 的 `character_substitution` 给了 3017 对映射，
`labels/kag_v5/` 已按此逐位替换。

### 1. ~~跳转标签只落地 108 / 1,366~~ ✅ 已解决

**根因**：跳转目标是**文件绝对偏移**（含 4 字节 "KSD1" 头），
正文偏移 = 目标 − 4。之前误用正文偏移，所以只对齐一成。

反编译证据：`FUN_0041f346(stream, offset, 0)` 第三参数 0 = `SEEK_SET`，
即 `lseek(fd, offset, 0)`。

修正后 **1365 / 1365（100%）** 落在命令边界。
